В данном документе представлен полный перечень переменных окружения приложения, сгруппированных по функциональным категориям, с описанием их назначения, формата значений и степени обязательности для работы системы.

### Примечания и рекомендации по безопасности:
1. **Шифрование 152-ФЗ**: переменная `STORE_ENCRYPTION_KEY` является критической. При её изменении база данных не сможет быть расшифрована без предварительной процедуры ротации ключей.
2. **Yandex SpeechKit**: для авторизации используется либо файл `authorized_key.json` (указывается в `YC_SERVICE_ACCOUNT_KEY_FILE`), либо статический секретный API-ключ `YC_API_KEY` (начинается на `AQVN...`).
3. **Развёртывание**: для быстрого старта скопируйте шаблон `.env.example` в `.env` и укажите боевые ключи телефонии и нейросетей.
